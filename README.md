# Creations — Luxury Event Management & Experiences

A modern, editorial luxury website for **Creations**, an India-wide event management company specializing in royal destination weddings, milestone birthday parties, corporate summits, and bespoke private celebrations.

Designed and implemented following the **UI/UX Pro Max methodology**.

## 🚀 Key Features

1. **Minimalist Luxury Navigation**: Floating header with scroll transition into warm ivory, active ScrollSpy indicators, and an accessible mobile drawer.
2. **Cinematic Hero**: Full-viewport editorial celebration scene with fluid clamp typography and dual conversion CTAs (*Plan My Event* / *Explore Our Work*).
3. **Editorial About Section**: Asymmetrical dual-photography composition with 4 verified trust pillars (*100+ Events Crafted, Pan-India, End-to-End Planning, Personalized Experiences*).
4. **Photo-Led Services Suite**: 8 curated event categories (Weddings, Corporate, Private Celebrations, Milestones, Concerts, Institutional, Destination Events, Bespoke Experiences) with quick inquiry links.
5. **Asymmetric Editorial Portfolio / Gallery**: Filterable showcase (Udaipur, Bengaluru, Jaipur, Goa, Mumbai, Delhi NCR) with interactive Story Lightbox dialogs.
6. **Why Creations**: 6 structured benefits with hairline dividers and numbered markers (avoiding generic cards).
7. **Process Timeline**: Horizontal desktop milestone sequence and connected vertical mobile timeline.
8. **Flexible Experience Packages**: Transparent tiers (*Essential*, *Signature*, *Bespoke*) that automatically pre-fill the inquiry form.
9. **Interactive Contact Form**: Accessible form inputs, client-side validation, direct WhatsApp and call integration, and submission confirmation feedback.
10. **Full Accessibility (WCAG 2.1 AA)**: Skip links, visible focus indicators, screen-reader semantics, and `prefers-reduced-motion` support.

## 🛠️ Deploying to GitHub Pages

1. Create a **Public** repository on [GitHub](https://github.com/new).
2. Upload `index.html` and `README.md`.
3. Navigate to **Settings > Pages**.
4. Set Source to **Deploy from a branch** (`main` / `/root`) and click **Save**.
5. Your website will be live in 1 minute!
